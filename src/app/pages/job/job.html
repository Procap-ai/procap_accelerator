How to run the tests

⬇ Download ZIP
  1. Install Node.js 18+ — nodejs.org
  2. Extract the ZIP and enter the folder: cd procap-tests
  3. Install dependencies & browsers: npm install && npx playwright install

  5. View the HTML report: npm run report

How to use the mabl script

⬇ Download ZIP
  1. Sign up at mabl — app.mabl.com (free trial available)
  2. Get your API key from Settings → APIs in the mabl dashboard.
  3. Extract the ZIP, open create_mabl_tests.sh, and set: MABL_API_KEY="your-api-key-here"
  4. Run the script: chmod +x create_mabl_tests.sh && ./create_mabl_tests.sh Creates your app and environment in mabl, triggers a deployment event.
  5. Record test journeys in the mabl web app and link them to a Plan.
💡 The ZIP also includes a README.md with full setup instructions. The script needs only curl and python3.
