How to run the tests

⬇ Download ZIP
  1. Install Node.js 18+ — nodejs.org
  2. Create a new Playwright project: npm init playwright@latest
  3. Extract the ZIP and copy playwright_test.spec.ts into the tests/ folder.
  4. Run the tests: npx playwright test playwright_test.spec.ts
  5. View the HTML report: npx playwright show-report

mabl Integration Script

How to use the mabl script

⬇ Download ZIP
  1. Sign up at mabl — app.mabl.com (free trial available)
  2. Get your API key from Settings → APIs in the mabl dashboard.
  3. Extract the ZIP and open create_mabl_tests.sh in a text editor.
  4. Fill in your credentials: MABL_API_KEY="your-api-key-here"
  5. Run the script: chmod +x create_mabl_tests.sh && ./create_mabl_tests.sh This creates your app and environment in mabl and triggers a deployment event.
  6. Record test journeys — open app.mabl.com, find your new app, and record tests using mabl's low-code recorder.
  7. Trigger test runs — re-run the script anytime to fire a deployment event and execute your linked Plans.
💡 The script uses only curl and python3 — available on macOS and Linux by default.
